Hosted Lifescape server

Privacy policy

Last updated: November 20, 2026

The short version

The Lifescape Claude plugin connects to the hosted server at https://lifescape.buildproven.ai/api/mcp. Each deployment serves one owner. The server keeps that owner's research in the owner's own database and nowhere else. It does not sell, share, or analyze the data. It sets one short-lived cookie during sign-in, to tie the GitHub sign-in to the browser that started it, and no tracking cookies.

What the hosted server stores

The server writes these records to the owner's own database (Postgres, such as Neon):

  • Research packets (table research_packets): the search profile and research brief you give, the candidate towns, the evidence values fetched for them with their sources and observation dates, and your approvals and rejections.
  • Comparison report indexes (table run_report_indexes): for each comparison run, the names of the report files it wrote and their SHA-256 digests.

The comparison report files themselves are written to the server's temporary working directory, which the hosting platform clears; they are not kept elsewhere. The server does not store your GitHub password or your GitHub access token.

The landing page and the demo store nothing. The demo uses invented evidence and runs no account.

Who can sign in

Only the owner's GitHub account can sign in. Claude signs in through GitHub, and the server gives a token only to the GitHub login set as the deployment's owner. Every other GitHub account is refused, and the tools answer 401 without a valid token.

Services that handle the data

  • GitHub confirms the signed-in login.
  • Vercel runs the server.
  • The owner's database provider (such as Neon) holds the records above.
  • Public data sources (the U.S. Census Bureau and NOAA) get the place you ask about when you fetch live evidence. They do not get your profile.

Each service handles data under its own privacy policy.

Delete your data

The data is in the owner's database, so the owner controls its deletion:

  1. To delete all records, run DROP TABLE research_packets, run_report_indexes; in the database, or delete the database (in Neon: the project's settings, then Delete project).
  2. To delete one research packet, delete its row: DELETE FROM research_packets WHERE packet_id = '<id>';
  3. To stop all access, remove the Lifescape connector in Claude and revoke the Lifescape OAuth app in GitHub (Settings, then Applications).
