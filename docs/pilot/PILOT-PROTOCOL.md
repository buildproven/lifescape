# Pilot protocol (PRD section 8)

The PRD's primary, activation, and explanation metrics are external pilot gates, not source-release
gates. **No pilot has been run; these metrics are `[unverified]`.** This file defines how to run
one and where to record it.

## Participants and session

Five distinct U.S. relocation-planning households, each in an unguided local session with no CSV
and no operator help. Record the session start time when the person first sees the app.

## Measures

| Metric | Pass |
|---|---|
| Primary | At least four of five save three or more towns they say they would spend 30 minutes researching ("Would you spend at least 30 minutes researching this town after this session?") within 10 minutes |
| Activation | At least four of five reach a recommendation list without preparing a CSV or operator assistance |
| Explanation | Each household names one displayed reason and one displayed trade-off for every saved town |

## Record

Copy this table into `docs/pilot/PILOT-RECORD-YYYY-MM-DD.md` per session.

| Session | Date | Started | Shortlist reached 3 at | Shortlist size | Interested yes/no per town | Reason and trade-off named per town | Operator help? | Notes |
|---|---|---|---|---|---|---|---|---|

Add a dimension to the catalog only when the pilot shows a repeated missing distinction (PRD
section 9), and only through a PRD amendment.
