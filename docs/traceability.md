# Requirements traceability matrix

V-model trace from each approved requirement in `docs/prd/lifescape-place-discovery.md` down to its
architecture and design, its code, and the tests that verify it. `tests/test_traceability.py`
fails when a requirement is missing, its quoted text no longer matches the PRD, or any reference
does not resolve to a real file and symbol. Update this table in the same change as any
requirement, design, code, or test change (PRD section 11).

```text
requirements (PRD) ─▶ architecture/design (ADR, docs) ─▶ code ─▶ unit/integration tests
        ▲                                                              │
        └───────── system and acceptance tests (browser journeys) ◀────┘
```
